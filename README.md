# PHP Blog Platform

A blog platform written in plain PHP and MySQL, without a framework, covering authentication, a user dashboard and content management.

## Features

- **Accounts:** register, log in and log out with PHP sessions.
- **Dashboard** for signed-in users.
- **Blogs:** write posts and manage your blogs.
- **User management** page.
- Shared layout (navbar and footer) across pages.

## Tech stack

PHP · MySQL · HTML/CSS

## Getting started

1. Copy the project into your web server folder (for example `C:\xampp\htdocs\php-rev`).
2. Create a MySQL database and set its name and credentials in `db.php`.
3. Open `http://localhost/php-rev` in your browser.
